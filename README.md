# 성경갈피 사이트

iOS 앱 **성경갈피**의 공개 페이지 세 장. App Store 심사에 필수인 개인정보처리방침·지원 URL을 제공한다.

| 파일 | 용도 |
|---|---|
| `index.html` | 앱 소개(홈) |
| `privacy.html` | 개인정보처리방침 — **App Store Connect ▸ 앱 개인정보 ▸ 방침 URL** |
| `support.html` | 지원 — **App Store Connect ▸ 지원 URL** |

- 순수 HTML 한 장씩. 스크립트·쿠키·외부 글꼴 요청이 없다(방침에 그렇게 적었으므로 실제로도 그렇게 유지한다).
- 링크는 모두 상대 경로다 — 프로젝트 페이지(`/galpi-site/`)와 사용자 도메인 루트 어디에 올려도 그대로 동작한다.
- 앱 안의 같은 내용(`PrivacyView`·FAQ)과 **문구를 일치시켜 관리한다.** 한쪽만 고치지 않는다.
  앱 저장소는 비공개(`colophonlabs/galpi`)이고, 이 저장소에는 방침·지원 문서만 둔다.
